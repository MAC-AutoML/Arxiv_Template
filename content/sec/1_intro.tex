\section{Introduction}

This template is intended to be the standard paper skeleton for the group. It keeps the shared visual identity while separating reusable template logic from paper-specific content.

When starting a new manuscript, authors should primarily edit `main.tex`, the files under `content/sec/`, and `references.bib`. Figures should be placed in `content/figures/`, while institutional and group logos should remain in `assets/branding/`.

The template supports a structured writing workflow and can be extended in a controlled way when a venue introduces special formatting requirements. A typical citation looks like this: \citep{lamport1994latex}.
